# Patterns that make text read as machine-written

Fix these when found, but never at the cost of meaning or accuracy.

- Stock openers and closers: "In today's fast-paced world", "In conclusion", "It is important to note that", "Overall,"
- Overused words: delve, leverage, robust, seamless, crucial, pivotal, tapestry, landscape, realm, holistic, multifaceted, underscores, comprehensive
- Rule-of-three lists used everywhere; every paragraph the same length
- Many sentences starting the same way (The..., This..., It...)
- Overused "not only X but also Y" and "it is not X, it is Y" constructions
- Hedging pileups: "may potentially", "can often help to"
- Em-dash overuse; bullet lists where a paragraph reads better
- Vague claims with no specifics ("significantly improves performance"). If the project has a real number, use it. If not, soften the claim or add [VERIFY]; never invent one.
- A closing sentence that merely repeats the paragraph
- Generic textbook definitions that could appear in any project's report
